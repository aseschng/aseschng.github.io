Local copies of the PreTeXt look, so the website needs no outside servers.

css/, js/   PreTeXt stylesheets and scripts (version 0.31 / js 0.13), taken from the
            copies already in this repository's old scripts/ folder. PreTeXt is free
            software (https://pretextbook.org).
fonts/      PT Serif, Open Sans and Inconsolata web fonts (from @fontsource),
            SIL Open Font License (see OFL-LICENSE.txt). css/fonts.css loads them.

You never need to edit these. Put your own style tweaks in theme/custom.css.
